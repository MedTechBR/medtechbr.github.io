Cifrar o painel-dados.json

Tudo acontece dentro deste navegador. O PIN não é enviado para lugar nenhum e não fica gravado em parte alguma — nem no arquivo gerado.

Use o mesmo PIN sempre. Se esquecer, é só cifrar de novo com outro — não há como recuperar o arquivo antigo.
  1. Suba o painel-dados.json baixado para o repositório, substituindo o anterior.
  2. Em 1 a 2 minutos o GitHub Pages publica. Puxe para baixo no app para recarregar.
  3. O app pede o PIN uma vez por sessão e guarda só até você fechar.
